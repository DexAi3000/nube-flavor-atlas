# NUBE — The Flavor Atlas · ready-to-paste prompts (dark theme)

Site look: a **near-black night board** (#0B0D12) with a faint dot grid. 13 tiles float on it, each one a
**dark jewel-tone world** lit low-key. Drag to pan, zoom, click a tile → it opens fullscreen and its video plays.

## How to use
0. **Best result:** upload a photo of a real salt bottle you like as a reference image and add: "Use the bottle from the reference image exactly (shape, cap, proportions), but replace the label with a blank design."
1. For each product: paste the **IMAGE** prompt → save the picture with the given name.
2. Then image-to-video: start frame = that picture, paste the **VIDEO** prompt → save with the given name.
3. Video settings: 16:9 · 1080p · 5 s. If the tool has them: **motion strength / creativity LOW** (Kling: relevance/cfg high ~0.7, "Professional" mode; Runway: motion 3–4; Hailuo: no "prompt optimizer"). Camera control = **static / none**.
   - Don't add anything to the video prompt about the product's look: the start frame already defines it. The prompt only describes what moves.
   - Make 2–3 takes, keep the one where the product stays sharp and still. Last frame doesn't need to match the first; the site plays it forward-and-back.
4. Put every file in `3dweb-projects/nube-atlas/raw/`.

Minimum to start: mango, bluerazz, watermelon, mint + pod-pen, vape-box.
